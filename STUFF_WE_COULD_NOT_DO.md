# Stuff we could not do

Leaving this to whoever wants to fork and go on.

- Make it so that every new installation of Ampersand had a "default dissociative state" that was named either "Unknown" or "Blurry";
- - Link this default dissociative state to a pinned "I don't know" button in the "Add to front" modal;
- Revamp the presence history so that every point of presence could have a summary of the moment from the person who was there and also a comment box for others to discuss;
- Replace a member, so that if two members were registered that happened to be one and the same, a user could easily correct their entire logs with a button;
- A split-merge relation between members, so that it was also possible to track them in the grand scheme of things;
- - A timeline of splits and merges would've been cool;
- Member likes and dislikes, in a way that could be linked to an "unblurring" screen that would ask the user about their likes and dislikes and rank the answers to the members;
- A revamp of the message board so that its style wasn't the only really uncanny thing... there's stuff to regret there.

This all could've landed in the 0.4.x series but we can't be there to make it anymore.
